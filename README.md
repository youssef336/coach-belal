# Coach Belal 🛋️→💪

كوتش جيم وتغذية بالذكاء الاصطناعي، معمول لأكسل حد في العالم.
بتكلمه بفويس أو بتصوّر أكلك، وهو بيحسب ويسجّل ويقترح بدائل أرخص في مصر، ويبنيلك برنامج تمرين بيتغيّر لوحده على حسب جسمك.

## المزايا

- **شات مع الكوتش زي واتساب**: تبعت فويس بالمصري أو صورة، وهو يرد بصوته ومعاه كروت فيها السعرات والبروتين والسعر، وبديل أرخص بزرار «تمام».
- **يومك جاهز**: الكوتش يقترح وجباتك، وإنت تعمل swipe: يمين يعني أكلته، وشمال يعني غيّره.
- **صوّر التلاجة**: يقولك تعمل إيه من الحاجات اللي عندك. **صوّر المنيو**: يختارلك أحسن أوردر.
- **«نفسي في حاجة»** و**«كسلان النهارده»**: أزرار جاهزة للحظات الضعف.
- **لستة سوبرماركت** للأسبوع بأرخص اختيارات، وتقدر تجيب أسعار النهارده من جوجل وتشاركها على واتساب.
- **برنامج تمرين بيتغيّر لوحده**: الكوتش يحلل كل عضلة اتمرنت قد إيه، والأرقام اللي وقفت، وصورة جسمك لو حبيت، ويبني برنامج 4–6 أسابيع آخرها أسبوع تخفيف، وبعدين يغيّره.
- **وضع الجيم**: زرار كبير مكتوب عليه «خلصت السِت»، والأوزان بتتملى من آخر مرة، وعدّاد الراحة بيهزّ لما يخلص. وكل تمرين له **أنيميشن بيشرحه شغال من غير نت**، وزرار فيديو على يوتيوب.
- **رتّب تمرينك بالسحب**: تسحب كروت التمارين من المكتبة وترتبها زي ما تحب.
- **شوف أدائي**: تصوّر سِت 10 ثواني والكوتش يقولك غلطاتك.
- **Boss Fight** كل أسبوع، ولفلات من «بطاطس كنبة» لحد «أسطورة»، وسلسلة أيام 🔥، وعدّاد للفلوس اللي وفّرتها.
- **Coach Wrapped**: ملخص أسبوعك على شكل ستوري ورأي الكوتش بصراحة.
- **تعديل السعرات لوحده** كل أسبوع لو الميزان واقف، و**وضع رمضان**.

كل بياناتك على تلفونك بس، ومفيش سيرفر.

## التشغيل

1. هات **مفتاح Gemini مجاني**: [aistudio.google.com/apikey](https://aistudio.google.com/apikey) ثم Create API key.
2. **أندرويد**: نزّل `coach-belal.apk` من [Releases](../../releases/latest) وسطّبه.
3. **آيفون**: افتح الرابط ده في Safari: `https://youssef336.github.io/coach-belal/`، وبعدين Share ثم **Add to Home Screen**.
4. افتح التطبيق، جاوب على أسئلة البداية (كلها سحب)، وبعدين من الإعدادات الزق المفتاح ودوس «احفظ وجرّب».

المفتاح بيتحفظ على تلفونك بس، ومش موجود في الكود.

## التطوير

```bash
flutter pub get
flutter run
flutter test
flutter test tool/make_icons_test.dart   # يرسم الأيقونات من الكوتش نفسه
flutter test tool/demo_sheet_test.dart   # صورة مراجعة لكل أنيميشن التمارين → build/demo_sheet.png
```

Flutter · Riverpod · Hive · Gemini API (REST). الكود في `lib/`:
`core/` (الثيم، التخزين، Gemini، الصوت) · `state/` (الأكل، التمارين، البرنامج، اللعبة) · `features/` (الشاشات).
